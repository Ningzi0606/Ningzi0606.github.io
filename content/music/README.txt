这个文件夹用来放音乐，右上角播放器 + 「音乐」页的曲目就是从这里自动扫描的。

【怎么加歌】
1. 把音频文件复制进来，支持 mp3 / m4a / aac / ogg / opus / wav / flac
2. 运行一次生成命令：node build/build.js
   （或者用 node build/serve.js --watch 启动预览，存盘自动重建）
3. 刷新网页，右上角播放器和「音乐」页都会出现新歌

【歌名 / 歌手 / 专辑 / 封面是从哪来的】
生成器会直接读取音频文件的 ID3 标签，优先级是：
  1. ID3 标签里的值（最准）
  2. 文件名，形如「歌手 - 歌名.mp3」会自动拆分
  3. 什么都没有就用文件名
内嵌在 ID3 里的封面图会被自动提取到 assets/music/cover-NN.jpg 当播放器封面。
所以想让播放器显示得漂亮，最省事的办法就是用带完整标签的音乐文件
（网易云、QQ音乐下载的文件通常都带标签和内嵌封面）。

【播放器说明】
- 右上角控件：封面 / 歌名 / 歌手·专辑 / 进度条 + 三个按钮
    ▶  点封面 = 播放/暂停；点歌名 = 切下一首
    ⟳  播放模式：连续播放 → 单曲循环 → 随机播放（点一下切一种，快捷键 M）
    ☰  播放列表：展开全部曲目，点任意一首直接播放（Esc 或点空白处关闭）
    🔊 静音开关
- 「音乐」页：大面板（封面 + 歌名 + 上一首/播放/下一首 + 进度条 + 时间）+ 完整曲目列表
- 播放状态是全站共用的：在「音乐」页点播放，切到别的页面不会断
- 快捷键：空格 播放/暂停，Shift+← / Shift+→ 快退快进 10 秒，M 切换播放模式
- 关掉网页再打开，会接着上次的曲目和进度继续

【三种播放模式的区别】
- 连续播放：按列表顺序循环，放完最后一首回到第一首
- 单曲循环：当前这首反复播，不会自动换歌
- 随机播放：把所有曲目打乱后依次播放，一轮内不重复，播完重新洗牌

【没有曲目时】
播放器会自动隐藏（右上角什么都不显示），不会留下一个空壳。
放进去至少一首歌，重新生成后就会出现。

【测试曲目】
build\make-demo-tracks.ps1 可以生成 3 首免版权的程序合成氛围曲，
用来体验播放模式和播放列表。不需要就直接删掉 demo-*.mp3。

【体积提醒】
音频比文字大得多，建议单个文件控制在 5 MB 以内（约 3~5 分钟的 192kbps mp3）。
wav / flac 体积很大（1 分钟 wav 约 10 MB），最好不要直接提交到 Git；
需要的话先转成 mp3。GitHub 单文件上限 100 MB，超过 50 MB 会警告。
